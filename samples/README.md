# Sample clips

Ten 5-second clips from **fold 5** of ESC-50 — the test fold, which the model never saw during training or
model selection. They let `uv run demo.py` run without downloading the full dataset. The clips were taken as
the first fold-5 clip of ten easy-to-recognise classes, not picked for being classified correctly; the model
gets 7 of the 10 right, in line with its 67 % test accuracy.
